# Общий браузер Hugin и помощника

Hugin может использовать установленный Google Chrome или Microsoft Edge и официальный браузерный
модуль ChatGPT в одном отдельном профиле hh.ru. Поиск, переписка и отклики
работают самостоятельно; помощник подключается к тому же браузеру через
расширение после его штатной установки и разрешения доступа к hh.ru.

## Первое подключение

В местном `.env` задайте `HUGIN_HH_BROWSER_CHANNEL=chrome` и перезапустите Hugin.
Chrome должен быть установлен. Прежний комплектный Chromium остаётся доступным
через `HUGIN_HH_BROWSER_CHANNEL=chromium`.

Для Microsoft Edge задайте `HUGIN_HH_BROWSER_CHANNEL=msedge`.
Установленное расширение ChatGPT в Edge поддерживается независимо от доступности
его установки в Chrome. Расширение должно быть подключено именно в используемом
профиле: наличие расширения в обычном профиле Edge не подключает новый профиль Hugin.

Профиль Chrome хранится отдельно: `%LOCALAPPDATA%/Hugin/browser-profiles/account-1-chrome`.
Профиль Edge также отдельный: `%LOCALAPPDATA%/Hugin/browser-profiles/account-1-edge`.
Старый профиль `account-1` не переносится автоматически: разные версии браузера
не должны попеременно обновлять его. В новом профиле нужно один раз войти в hh.ru
и подключить официальное расширение по [инструкции OpenAI](https://learn.chatgpt.com/docs/chrome-extension).
Проверяйте выбранный аккаунт hh.ru. Установка расширения в другом профиле не даёт
доступ к сессии Hugin. Полное подключение подтверждается появлением именно этого
профиля в инструментах браузера и чтением его страницы.

## Передача управления

Обычная работа настольного Hugin запускает браузер без окна. Служебные вкладки
скрыты: поиск, отклики и чтение переписки не должны выводить браузер поверх игры.
Для ручного входа или анкеты Hugin сначала ждёт завершения автоматических действий,
сохраняет профиль и открывает оконный браузер с тем же профилем. После возврата
управления оконный браузер закрывается и Hugin снова запускает его без окна,
сохранив тот же профиль.

Первая ручная передача после запуска меняет местный служебный адрес браузера;
используйте адрес только после подтверждения готовности передачи.

При работающем Hugin выполните:

```powershell
uv run python -m hugin.browser_control_cli acquire --url https://hh.ru/account/captcha
```

Команда ждёт завершения текущих действий и возвращает `state=ready`, номер `token`
и срок `expires_at`. До `ready` нельзя считать браузер переданным помощнику.
После подтверждения новые фоновые действия браузера ждут, а помощник работает
через штатное расширение. Настройки процессов, режим ресурсов и правила отправки
не меняются. Подключение служебного браузера остаётся местным, на `127.0.0.1`.

В окне Hugin во всех разделах отображается подготовка передачи или ручная работа
с временем окончания. Неудачная передача и недоступность проверки состояния
показываются отдельно. После возврата либо истечения срока плашка исчезает;
это не включает остановленные пользователем процессы и не снимает защиту аккаунта.

```powershell
uv run python -m hugin.browser_control_cli status
uv run python -m hugin.browser_control_cli release НОМЕР_TOKEN
```

Обычный срок передачи — 30 минут; `--minutes` позволяет выбрать от 1 до 60 минут.
После возврата либо окончания срока прежняя автоматика снова получает доступ.
Если работа не закончена, верните управление и запросите новый срок до продолжения.
Номер прежней передачи не может отменить более новую. При ошибке или тайм-ауте
команда снимает только собственный запрос.

Ручной вход и анкеты в окне Hugin используют ту же передачу управления; на это
время поиск и отправки также уступают браузер. Закрытие клиентской вкладки не
закрывает общий браузер. Возврат управления сам по себе не снимает капчу,
предупреждение аккаунта или пользовательскую паузу: для восстановления авторизации
используется штатный вход Hugin после фактического завершения проверки hh.ru.
