# Работа над Hugin

Пиши просто и по-русски. Работай в текущей ветке. Ветки, коммиты, отправки в удалённый репозиторий и PR выполняй только по прямому поручению. Прежние планы не расширяют текущее поручение.

Ясную местную задачу доводи до проверенного результата самостоятельно. Уточняй решения, существенно меняющие результат, объём поручения или разрешённые действия. Это заменяет обязательные промежуточные согласования навыков.

Перед действием открой указанный раздел [CODING_STANDARDS.md](CODING_STANDARDS.md), а не весь документ:

| Действие | Раздел |
| --- | --- |
| Изменение существующей части местного проекта или продолжение прежней работы | Местный `.project-notes/LOCAL_OPERATIONS.md`, раздел «Контекст» |
| Изменение исходников | [Изменения](CODING_STANDARDS.md#изменения), [Проверки](CODING_STANDARDS.md#проверки) |
| Изменение или запуск проверок; правка только текста | [Проверки](CODING_STANDARDS.md#проверки) |
| Работа с основной установкой, базой или личным аккаунтом; запуск Docker/Hugin; внешнее действие; требование остановленных отправок | [Установка и данные](CODING_STANDARDS.md#установка-и-данные) |
| Разбор сбоя, старой операции или оценка доказательств | [Доказательства](CODING_STANDARDS.md#доказательства) |
| Завершение нововведения, исправления или пересмотра проблемы/оценки; новые доказательства | [Завершение](CODING_STANDARDS.md#завершение) |
| Разрешённый коммит, отправка в репозиторий или PR | [Публикация](CODING_STANDARDS.md#публикация) |

Если указанный местный файл отсутствует, продолжай разрешённую разработку
и независимый разбор. Недоступные сведения и проверки отметь как пробел;
неизвестные личные разрешения и условия запуска выясни до зависимого действия.
